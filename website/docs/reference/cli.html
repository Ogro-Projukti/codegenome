CLI overview

How to invoke

MethodWhen to use
codegenome …Primary user-facing CLI (Click)
python -m codegenome …Legacy flag CLI, dev without PATH
python -m codegenome.mcp_server …Standalone MCP (custom port/stdio)
python -m codegenome.installer …Write MCP config for AI clients

Help

codegenome --help
python -m codegenome --help
python -m codegenome.mcp_server --help

Subcommands (Click CLI)

  • analyze — build knowledge graph
  • export — export graph to a format
  • mcp-start — start MCP server (stdio)
  • evolve — watch + live browser UI
  • rules — generate agent rule files
  • tui — terminal dashboard

Details: Command reference.

Workspace

Most commands accept a path argument (default .). All artifacts are stored under <workspace>/.genome/.

Exit codes

  • 0 — success
  • 1 — error (message on stderr)
